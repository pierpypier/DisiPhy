12 - Esercizi svolti: equazioni di secondo grado

Esercizio 1 - Equazione monomia

Esempio: Risolvere l'equazione 5x2 = 0.

Dividiamo entrambi i membri per 5.

x2 = 0 → x = 0 (soluzione doppia)

Esercizio 2 - Equazione pura con soluzioni reali

Esempio: Risolvere l'equazione 3x2 - 27 = 0.

Isoliamo x2 ed estraiamo la radice quadrata.

3x2 = 27 → x2 = 9 → x = ±√9 = ±3

Le soluzioni sono x = 3 e x = -3.

Esercizio 3 - Equazione pura senza soluzioni reali

Esempio: Risolvere l'equazione x2 + 4 = 0.

x2 = -4

Non esiste alcun numero reale il cui quadrato sia negativo: l'equazione non ha soluzioni reali.

Esercizio 4 - Equazione spuria

Esempio: Risolvere l'equazione 4x2 + 12x = 0.

Raccogliamo x a fattor comune e applichiamo la legge di annullamento del prodotto.

x(4x + 12) = 0 → x = 0 oppure 4x + 12 = 0 → x = -3

Le soluzioni sono x = 0 e x = -3.

Esercizio 5 - Formula risolutiva generale, Δ > 0

Esempio: Risolvere l'equazione x2 + 2x - 15 = 0.

Identifichiamo a = 1, b = 2, c = -15 e calcoliamo il discriminante.

Δ = 22 - 4×1×(-15) = 4 + 60 = 64

Poiché Δ > 0, applichiamo la formula risolutiva.

x = (-2 ± √64) / 2 = (-2 ± 8) / 2

Le soluzioni sono x = (-2+8)/2 = 3 e x = (-2-8)/2 = -5. Verifichiamo la prima: 32 + 2×3 - 15 = 9 + 6 - 15 = 0.

Esercizio 6 - Formula risolutiva generale, Δ = 0

Esempio: Risolvere l'equazione x2 - 8x + 16 = 0.

Δ = (-8)2 - 4×1×16 = 64 - 64 = 0

Poiché Δ = 0, l'equazione ha una soluzione doppia, data da x = -b/(2a).

x = -(-8) / (2×1) = 8/2 = 4

Verifichiamo: 42 - 8×4 + 16 = 16 - 32 + 16 = 0.

Esercizio 7 - Formula risolutiva generale, Δ < 0

Esempio: Risolvere l'equazione x2 + x + 3 = 0.

Δ = 12 - 4×1×3 = 1 - 12 = -11

Poiché Δ è negativo, l'equazione non ha soluzioni reali: è impossibile in ℝ.

Esercizio 8 - Formula ridotta

Esempio: Risolvere con la formula ridotta l'equazione x2 - 10x + 21 = 0.

Il coefficiente b = -10 è pari, quindi b' = -5. Applichiamo la formula ridotta con a = 1, c = 21.

x = (5 ± √(25 - 21)) / 1 = 5 ± √4 = 5 ± 2

Le soluzioni sono x = 7 e x = 3. Verifichiamo la prima: 72 - 10×7 + 21 = 49 - 70 + 21 = 0.

Esercizio 9 - Verifica con le relazioni di Viète

Esempio: L'equazione x2 - 7x + 12 = 0 ha soluzioni x1 = 3 e x2 = 4. Verificare le relazioni tra coefficienti e soluzioni.

Con a = 1, b = -7, c = 12, calcoliamo somma e prodotto attesi dalle relazioni di Viète.

x1 + x2 = -b/a → 3 + 4 = 7 = -(-7)/1

x1 × x2 = c/a → 3 × 4 = 12 = 12/1

Entrambe le relazioni sono verificate.

Esercizio 10 - Ricostruire un'equazione dalle sue soluzioni

Esempio: Scrivere un'equazione di secondo grado (con a = 1) che abbia come soluzioni x1 = 2 e x2 = 5.

Utilizziamo le relazioni di Viète al contrario: il coefficiente b è l'opposto della somma delle soluzioni, il termine noto c è il loro prodotto.

x1 + x2 = 7 → b = -7     x1 × x2 = 10 → c = 10

x2 - 7x + 10 = 0

Esercizio 11 - Scomposizione del trinomio di secondo grado

Esempio: Scomporre in fattori il trinomio 3x2 - 3x - 18.

Risolviamo l'equazione associata 3x2 - 3x - 18 = 0, cioè x2 - x - 6 = 0 dopo aver diviso per 3: cerchiamo due numeri il cui prodotto sia -6 e la cui somma sia 1, cioè 3 e -2.

x1 = 3, x2 = -2

3x2 - 3x - 18 = 3(x - 3)(x + 2)

Verifichiamo sviluppando: 3(x - 3)(x + 2) = 3(x2 - x - 6) = 3x2 - 3x - 18.

Esercizio 12 - Esercizio riepilogativo: formula ridotta e verifica con Viète

Esempio: Risolvere l'equazione 2x2 - 4x - 6 = 0 con la formula ridotta, e verificare il risultato con le relazioni di Viète.

Con a = 2, b = -4 (quindi b' = -2), c = -6, applichiamo la formula ridotta.

x = (2 ± √(4 - 2×(-6))) / 2 = (2 ± √(4 + 12)) / 2 = (2 ± √16) / 2 = (2 ± 4) / 2

Le soluzioni sono x = 3 e x = -1. Verifichiamo con le relazioni di Viète.

x1 + x2 = -b/a → 3 + (-1) = 2 = -(-4)/2

x1 × x2 = c/a → 3 × (-1) = -3 = -6/2

Entrambe le relazioni sono verificate, confermando la correttezza delle soluzioni trovate.
