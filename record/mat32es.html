32 - Esercizi svolti: equazioni e disequazioni goniometriche

Esercizio 1 - Equazione elementare in seno

Esempio: Risolvere l'equazione sin x = √2/2.

Sappiamo che sin(π/4) = √2/2, quindi α = π/4.

x = π/4 + 2kπ ∨ x = π - π/4 + 2kπ = 3π/4 + 2kπ , con k ∈ ℤ

Esercizio 2 - Equazione elementare in coseno

Esempio: Risolvere l'equazione cos x = -1/2.

Cerchiamo l'angolo del primo giro il cui coseno vale -1/2: sappiamo che cos(2π/3) = -1/2, quindi α = 2π/3.

x = ±2π/3 + 2kπ , con k ∈ ℤ

Esercizio 3 - Equazione elementare in tangente

Esempio: Risolvere l'equazione tan x = 1.

Sappiamo che tan(π/4) = 1, quindi α = π/4.

x = π/4 + kπ , con k ∈ ℤ

Esercizio 4 - Equazione impossibile

Esempio: Risolvere l'equazione sin x = 2.

Poiché il seno di un angolo non può mai superare 1 in valore assoluto, questa equazione non ha soluzioni: è impossibile.

Esercizio 5 - Equazione omogenea in seno e coseno

Esempio: Risolvere l'equazione √3 sin x - cos x = 0.

Verifichiamo che cos x = 0 non sia soluzione: se lo fosse, dovrebbe esserlo anche sin x = 0, il che è impossibile per la prima relazione fondamentale. Dividiamo quindi tutto per cos x.

√3 tan x - 1 = 0 → tan x = 1/√3 = √3/3

Riconosciamo questo come il valore notevole della tangente di 30°.

x = π/6 + kπ , con k ∈ ℤ

Esercizio 6 - Disequazione elementare in seno

Esempio: Risolvere la disequazione sin x < 1/2, nell'intervallo [0, 2π).

I punti in cui sin x = 1/2 sono x = π/6 e x = 5π/6. L'ordinata è minore di 1/2 al di fuori dell'arco compreso tra questi due angoli.

0 ≤ x < π/6 ∨ 5π/6 < x < 2π

Esercizio 7 - Disequazione elementare in coseno

Esempio: Risolvere la disequazione cos x > √2/2, nell'intervallo [0, 2π).

I punti in cui cos x = √2/2 sono x = π/4 e x = 7π/4. L'ascissa è maggiore di √2/2 nell'arco vicino a x = 0, cioè all'esterno dell'intervallo tra questi due angoli.

0 ≤ x < π/4 ∨ 7π/4 < x < 2π

Esercizio 8 - Disequazione elementare in tangente

Esempio: Risolvere la disequazione tan x > 1, nell'intervallo (-π/2, π/2).

Sappiamo che tan(π/4) = 1. Essendo la tangente crescente in questo intervallo, la disequazione è verificata per gli angoli maggiori di π/4, fino all'asintoto verticale.

π/4 < x < π/2

Esercizio 9 - Sistema di disequazioni: seno negativo e coseno positivo

Esempio: Risolvere il sistema formato da sin x < 0 e cos x > 0, nell'intervallo [0, 2π).

La prima disequazione è verificata nel terzo e quarto quadrante (π < x < 2π). La seconda è verificata nel primo e quarto quadrante (0 ≤ x < π/2 ∨ 3π/2 < x < 2π).

L'intersezione dei due archi corrisponde esattamente al quarto quadrante, l'unico in cui il seno è negativo e il coseno è positivo contemporaneamente.

3π/2 < x < 2π

Esercizio 10 - Sistema di disequazioni: seno e tangente positivi

Esempio: Risolvere il sistema formato da sin x > 0 e tan x > 0, nell'intervallo [0, 2π).

La prima disequazione è verificata nel primo e secondo quadrante (0 < x < π). La seconda è verificata nel primo e terzo quadrante (0 < x < π/2 ∨ π < x < 3π/2).

L'intersezione dei due archi corrisponde al solo primo quadrante, dove sia il seno sia la tangente sono positivi.

0 < x < π/2

Esercizio 11 - Equazione elementare con valore negativo del seno

Esempio: Risolvere l'equazione sin x = -1/2.

Conviene scegliere come angolo di riferimento α = -π/6, dato che sin(-π/6) = -1/2.

x = -π/6 + 2kπ ∨ x = π - (-π/6) + 2kπ = 7π/6 + 2kπ , con k ∈ ℤ

Esercizio 12 - Esercizio riepilogativo: equazione con condizione aggiuntiva

Esempio: Tra le soluzioni dell'equazione cos x = 1/2 nell'intervallo [0, 2π), trovare quelle che soddisfano anche la condizione sin x > 0.

Le soluzioni dell'equazione cos x = 1/2 nell'intervallo dato sono due.

x = π/3 ∨ x = 5π/3

Verifichiamo il segno del seno in entrambi i casi: sin(π/3) = √3/2, che è positivo, mentre sin(5π/3) = -√3/2, che è negativo. Solo la prima soluzione soddisfa la condizione richiesta.

x = π/3
