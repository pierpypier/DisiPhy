41 - Esercizi svolti: lo studio di funzione

Esercizio 1 - Dominio di una funzione razionale fratta

Esempio: Determinare il dominio di f(x) = (2x-1) / (x2-4).

x2-4 ≠ 0 → x ≠ ±2

Esercizio 2 - Verificare la simmetria di una funzione

Esempio: Verificare se f(x) = x4 - 2x2 + 1 è pari, dispari, o nessuna delle due.

f(-x) = (-x)4 - 2(-x)2 + 1 = x4 - 2x2 + 1 = f(x)

Poiché f(-x) = f(x), la funzione è pari.

Esercizio 3 - Studio del segno

Esempio: Studiare il segno di f(x) = (x-1) / (x+2).

Il numeratore è ≥ 0 per x ≥ 1; il denominatore è > 0 per x > -2. La frazione è positiva quando numeratore e denominatore hanno lo stesso segno.

f(x) > 0 per x < -2 ∨ x > 1 ; f(x) < 0 per -2 < x < 1

Esercizio 4 - Asintoto verticale e orizzontale

Esempio: Determinare gli asintoti di f(x) = 3 / (x-2).

Il denominatore si annulla in x = 2, dove il limite della funzione è infinito.

limx→2 f(x) = ∞ → asintoto verticale x = 2

Per x che tende a infinito, il grado del numeratore è minore di quello del denominatore, quindi il limite è zero.

limx→∞ f(x) = 0 → asintoto orizzontale y = 0

Esercizio 5 - Asintoto obliquo

Esempio: Determinare l'asintoto obliquo di f(x) = (x2+1) / x.

Il grado del numeratore supera di esattamente 1 quello del denominatore: ci aspettiamo un asintoto obliquo.

m = limx→∞ f(x)/x = limx→∞ (x2+1)/x2 = 1

q = limx→∞ [f(x) - mx] = limx→∞ [(x2+1)/x - x] = limx→∞ 1/x = 0

L'asintoto obliquo è quindi y = x.

Esercizio 6 - Derivata prima: punti di massimo e minimo

Esempio: Studiare la derivata prima di f(x) = x3 - 6x2, per trovare i punti di massimo e minimo relativo.

f'(x) = 3x2 - 12x = 3x(x-4)

La derivata si annulla per x = 0 e x = 4. Studiando il segno, f'(x) è positiva per x < 0 ∨ x > 4, negativa per 0 < x < 4.

x = 0 è un massimo relativo ; x = 4 è un minimo relativo

Esercizio 7 - Derivata seconda: punto di flesso

Esempio: Calcolare la derivata seconda di f(x) = x3 - 6x2 (dall'Esercizio 6) e trovare l'eventuale punto di flesso.

f''(x) = 6x - 12

La derivata seconda si annulla per x = 2, e cambia effettivamente segno (negativa per x < 2, positiva per x > 2).

x = 2 è un punto di flesso

Come nel caso visto nel capitolo, il flesso si trova esattamente a metà strada tra il massimo (x=0) e il minimo (x=4).

Esercizio 8 - Flesso a tangente orizzontale

Esempio: Studiare il punto stazionario di f(x) = x3 in x = 0.

f'(x) = 3x2

La derivata si annulla in x = 0, ma è sempre maggiore o uguale a zero, senza mai cambiare segno: x = 0 non è quindi né massimo né minimo, ma un flesso a tangente orizzontale.

Confermiamo con la derivata seconda: f''(x) = 6x, che si annulla in x = 0 e cambia effettivamente segno (negativa per x < 0, positiva per x > 0), confermando che si tratta di un punto di flesso.

Esercizio 9 - Studio di una funzione razionale: dominio, segno e asintoti

Esempio: Studiare dominio, segno, intersezioni e asintoti di f(x) = (x-3) / (x+1).

Dominio: x ≠ -1

Il numeratore è ≥ 0 per x ≥ 3, il denominatore è > 0 per x > -1.

f(x) > 0 per x < -1 ∨ x > 3 ; f(x) < 0 per -1 < x < 3

L'intersezione con l'asse x è (3, 0); l'intersezione con l'asse y è f(0) = -3/1 = -3, cioè il punto (0, -3).

asintoto verticale: x = -1     asintoto orizzontale: y = 1 (gradi uguali, rapporto dei coefficienti)

Esercizio 10 - Derivata prima di una funzione sempre crescente

Esempio: Calcolare la derivata prima di f(x) = (x-3) / (x+1) (dall'Esercizio 9) e studiarne il segno.

f'(x) = [(1)(x+1) - (x-3)(1)] / (x+1)2 = (x+1-x+3) / (x+1)2 = 4 / (x+1)2

Il numeratore è sempre positivo (4) e il denominatore è un quadrato, sempre positivo nel dominio: la derivata è quindi sempre positiva, e la funzione è sempre crescente, senza alcun punto stazionario.

Esercizio 11 - Concavità di una funzione con asintoto obliquo

Esempio: Studiare la concavità di f(x) = (x2+1)/x = x + 1/x (dall'Esercizio 5), calcolando la derivata seconda.

f'(x) = 1 - 1/x2     f''(x) = 2/x3

Per x > 0, f''(x) è positiva: concavità verso l'alto. Per x < 0, f''(x) è negativa: concavità verso il basso. Non essendo x = 0 parte del dominio, questo cambio di concavità non corrisponde a un punto di flesso della funzione.

Esercizio 12 - Esercizio riepilogativo: studio quasi completo di una funzione

Esempio: Studiare dominio, segno, asintoti e derivata prima di f(x) = x2 / (x-1).

Dominio: x ≠ 1

Il numeratore x2 è sempre ≥ 0 (si annulla solo in x = 0); il denominatore è positivo per x > 1.

f(x) > 0 per x > 1 ; f(x) < 0 per x < 1 (tranne in x = 0, dove f(x) = 0)

L'unica intersezione con gli assi è l'origine (0, 0). Il denominatore si annulla in x = 1, dove il limite è infinito.

asintoto verticale: x = 1

Poiché il grado del numeratore (2) supera di 1 quello del denominatore (1), eseguiamo la divisione polinomiale per trovare l'asintoto obliquo.

x2 / (x-1) = x + 1 + 1/(x-1) → asintoto obliquo: y = x + 1

Calcoliamo infine la derivata prima.

f'(x) = [2x(x-1) - x2] / (x-1)2 = (x2-2x) / (x-1)2 = x(x-2) / (x-1)2

La derivata si annulla per x = 0 e x = 2. Essendo il denominatore sempre positivo, il segno dipende solo dal numeratore x(x-2): positivo per x < 0 ∨ x > 2, negativo per 0 < x < 2 (con x = 1 escluso dal dominio).

x = 0 è un massimo relativo (f(0)=0) ; x = 2 è un minimo relativo (f(2)=4)
