12 - Equazioni di secondo grado - Classe 2

Che cos'è un'equazione di secondo grado

Un'equazione di secondo grado è un'equazione in cui l'incognita compare, dopo aver svolto tutti i calcoli, con esponente massimo uguale a 2. La forma normale di un'equazione di secondo grado è la seguente, dove a, b e c sono numeri reali detti coefficienti, con la condizione che a sia diverso da zero (altrimenti l'equazione sarebbe di primo grado).

ax2 + bx + c = 0

Il coefficiente a si chiama coefficiente del termine di secondo grado, b coefficiente del termine di primo grado, c termine noto. In base ai valori di questi coefficienti, un'equazione di secondo grado si classifica in modi diversi.

Se sia b sia c sono diversi da zero, l'equazione si dice completa. Se b è uguale a zero, l'equazione si dice pura, e ha la forma ax2 + c = 0. Se c è uguale a zero, l'equazione si dice spuria, e ha la forma ax2 + bx = 0. Se sia b sia c sono uguali a zero, l'equazione si dice monomia, e ha la forma ax2 = 0.

Risoluzione delle equazioni incomplete

Le equazioni incomplete si risolvono con metodi più rapidi rispetto alla formula generale, che vedremo tra poco per il caso completo.

Un'equazione monomia ax2 = 0 si risolve dividendo per a: si ottiene x2 = 0, la cui unica soluzione è x = 0 (contata, come vedremo, due volte).

Un'equazione pura ax2 + c = 0 si risolve isolando x2 ed estraendo la radice quadrata di entrambi i membri.

x2 = -c/a → x = ±√(-c/a)

Risolviamo l'equazione pura 2x2 - 8 = 0. Isoliamo x2.

2x2 = 8 → x2 = 4 → x = ±√4 = ±2

Le soluzioni sono quindi x = 2 e x = -2. Se invece il valore -c/a fosse risultato negativo, l'equazione pura non avrebbe avuto soluzioni reali, perché non esiste alcun numero reale il cui quadrato sia negativo.

Un'equazione spuria ax2 + bx = 0 si risolve raccogliendo x a fattor comune, ottenendo il prodotto di due fattori uguagliato a zero: si applica quindi la legge di annullamento del prodotto, per cui un prodotto è nullo se e solo se almeno uno dei suoi fattori è nullo.

x(ax + b) = 0 → x = 0 oppure ax + b = 0 → x = -b/a

Risolviamo l'equazione spuria 3x2 - 6x = 0. Raccogliamo x a fattor comune.

x(3x - 6) = 0 → x = 0 oppure 3x - 6 = 0 → x = 2

Le soluzioni sono quindi x = 0 e x = 2. Un'equazione spuria ha sempre lo zero tra le sue soluzioni.

La formula risolutiva generale

Per risolvere un'equazione completa, si utilizza la formula risolutiva generale, ottenuta con la tecnica del completamento del quadrato applicata alla forma normale ax2 + bx + c = 0.

x = (-b ± √(b2 - 4ac)) / (2a)

L'espressione sotto il segno di radice, b2 - 4ac, si chiama discriminante dell'equazione e si indica solitamente con la lettera greca Δ (delta), perché il suo segno determina completamente il numero di soluzioni reali dell'equazione.

Δ = b2 - 4ac

Risolviamo l'equazione x2 - 5x + 6 = 0, con a = 1, b = -5, c = 6. Calcoliamo prima il discriminante.

Δ = (-5)2 - 4×1×6 = 25 - 24 = 1

Poiché Δ è positivo, applichiamo la formula risolutiva.

x = (5 ± √1) / 2 = (5 ± 1) / 2

Otteniamo così le due soluzioni: x = (5+1)/2 = 3 e x = (5-1)/2 = 2.

Il segno del discriminante

Il valore del discriminante Δ permette di sapere, ancora prima di completare i calcoli, quante soluzioni reali avrà l'equazione, senza bisogno di calcolarle esplicitamente.

Se Δ è maggiore di zero, l'equazione ha due soluzioni reali e distinte, date dalla formula risolutiva con il doppio segno.

Se Δ è uguale a zero, l'equazione ha un'unica soluzione reale, detta anche soluzione doppia, perché la formula risolutiva si riduce a x = -b/(2a), dato che la radice del discriminante nullo è zero.

Se Δ è minore di zero, l'equazione non ha soluzioni reali, perché non esiste alcun numero reale che sia la radice quadrata di un numero negativo: si dice in questo caso che l'equazione è impossibile in ℝ. (Il capitolo sui numeri complessi mostrerà come, in un insieme numerico più ampio, anche queste equazioni ammettano soluzione.)

Verifichiamo con un esempio il caso Δ = 0: risolviamo x2 - 4x + 4 = 0.

Δ = (-4)2 - 4×1×4 = 16 - 16 = 0

La soluzione doppia è quindi x = -(-4)/(2×1) = 4/2 = 2.

La formula ridotta

Quando il coefficiente b è un numero pari, oppure quando b/2 è comunque un numero intero, conviene utilizzare la formula ridotta, che semplifica i calcoli evitando alcuni passaggi. Si pone b = 2b', dove b' è la metà di b.

x = (-b' ± √(b'2 - ac)) / a

Risolviamo con la formula ridotta l'equazione x2 - 6x + 5 = 0, dove b = -6, quindi b' = -3.

x = (3 ± √(9 - 5)) / 1 = 3 ± √4 = 3 ± 2

Le soluzioni sono quindi x = 5 e x = 1, ottenute con calcoli leggermente più rapidi rispetto alla formula generale.

Relazioni tra coefficienti e soluzioni

Esistono due relazioni molto utili, note come relazioni di Viète (o formule di Girard), che legano direttamente i coefficienti di un'equazione di secondo grado alla somma e al prodotto delle sue soluzioni, senza bisogno di calcolarle esplicitamente.

x1 + x2 = -b/a , x1 × x2 = c/a

Queste relazioni sono utili anche per ricostruire un'equazione a partire dalle sue soluzioni, oppure per verificare rapidamente la correttezza di soluzioni già trovate. Verifichiamo, per l'equazione x2 - 5x + 6 = 0 risolta sopra, che le relazioni siano soddisfatte: la somma delle soluzioni è 3 + 2 = 5, che coincide con -b/a = 5; il prodotto è 3 × 2 = 6, che coincide con c/a = 6.

Scomposizione del trinomio di secondo grado

Le relazioni appena viste permettono anche di scomporre in fattori un qualsiasi trinomio di secondo grado ax2 + bx + c, purché il discriminante non sia negativo, utilizzando le soluzioni x1 e x2 dell'equazione associata.

ax2 + bx + c = a(x - x1)(x - x2)

Scomponiamo il trinomio 2x2 - 2x - 4. Risolviamo prima l'equazione associata 2x2 - 2x - 4 = 0, cioè x2 - x - 2 = 0 dopo aver diviso per 2: troviamo x1 = 2 e x2 = -1.

2x2 - 2x - 4 = 2(x - 2)(x + 1)

Questo metodo generalizza la tecnica del trinomio notevole vista nel capitolo sulla scomposizione, e funziona anche quando i due numeri cercati non sono facilmente individuabili "a mente".
