40 - Esercizi svolti: i teoremi del calcolo differenziale

Esercizio 1 - Teorema di Rolle: funzione polinomiale

Esempio: Verificare il teorema di Rolle per f(x) = x2 - 6x + 8 nell'intervallo [2, 4].

f(2) = 4 - 12 + 8 = 0     f(4) = 16 - 24 + 8 = 0

Poiché f(2) = f(4) e la funzione, essendo un polinomio, è continua e derivabile ovunque, le ipotesi sono verificate. Troviamo il punto c.

f'(x) = 2x - 6 → 2c - 6 = 0 → c = 3

Il punto c = 3 appartiene effettivamente all'intervallo (2, 4).

Esercizio 2 - Teorema di Rolle: funzione trigonometrica

Esempio: Verificare il teorema di Rolle per f(x) = sin x nell'intervallo [0, π].

f(0) = 0     f(π) = 0

La funzione seno è continua e derivabile ovunque, e assume lo stesso valore agli estremi. Troviamo il punto c.

f'(x) = cos x → cos(c) = 0 → c = π/2

Il punto c = π/2 appartiene effettivamente all'intervallo (0, π).

Esercizio 3 - Teorema di Lagrange: primo esempio

Esempio: Verificare il teorema di Lagrange per f(x) = x2 nell'intervallo [1, 5].

[f(5) - f(1)] / (5-1) = (25-1)/4 = 24/4 = 6

f'(x) = 2x → 2c = 6 → c = 3

Il punto c = 3 appartiene effettivamente all'intervallo (1, 5).

Esercizio 4 - Teorema di Lagrange: funzione cubica

Esempio: Verificare il teorema di Lagrange per f(x) = x3 nell'intervallo [1, 3].

[f(3) - f(1)] / (3-1) = (27-1)/2 = 26/2 = 13

f'(x) = 3x2 → 3c2 = 13 → c2 = 13/3 → c = √(13/3) ≈ 2,08

Il punto trovato appartiene effettivamente all'intervallo (1, 3).

Esercizio 5 - Monotonia tramite il segno della derivata

Esempio: Studiare la monotonia di f(x) = x3 - 12x, individuando eventuali punti di massimo e minimo relativo.

f'(x) = 3x2 - 12 = 3(x2-4) = 3(x-2)(x+2)

Studiando il segno di questo prodotto, f'(x) > 0 per x < -2 ∨ x > 2, e f'(x) < 0 per -2 < x < 2.

f crescente per x < -2 ∨ x > 2 ; f decrescente per -2 < x < 2

Il punto x = -2 è quindi un massimo relativo (la funzione passa da crescente a decrescente), mentre x = 2 è un minimo relativo (la funzione passa da decrescente a crescente).

Esercizio 6 - Teorema di Cauchy

Esempio: Verificare il teorema di Cauchy per f(x) = x2 e g(x) = x3 nell'intervallo [1, 2].

[f(2)-f(1)] / [g(2)-g(1)] = (4-1) / (8-1) = 3/7

f'(x)/g'(x) = 2x / (3x2) = 2/(3x)

Imponiamo l'uguaglianza per trovare c.

2/(3c) = 3/7 → 14 = 9c → c = 14/9 ≈ 1,56

Il punto trovato appartiene effettivamente all'intervallo (1, 2).

Esercizio 7 - De l'Hôpital: forma 0/0

Esempio: Calcolare, applicando De l'Hôpital, limx→0 (ex-1) / x.

Sostituendo x = 0 si otterrebbe 0/0. Deriviamo numeratore e denominatore separatamente.

limx→0 (ex-1)/x = limx→0 ex/1 = e0 = 1

Esercizio 8 - De l'Hôpital: forma ∞/∞

Esempio: Calcolare, applicando De l'Hôpital, limx→+∞ (ln x) / x.

Per x → +∞, sia il numeratore sia il denominatore tendono a +∞: forma ∞/∞.

limx→+∞ (ln x)/x = limx→+∞ (1/x)/1 = limx→+∞ 1/x = 0

Esercizio 9 - De l'Hôpital applicato due volte

Esempio: Calcolare limx→0 (1 - cos x) / x2.

Sostituendo x = 0 si otterrebbe 0/0. Applichiamo De l'Hôpital una prima volta.

limx→0 (1-cos x)/x2 = limx→0 (sin x) / (2x)

Anche questo limite si presenta nella forma 0/0: applichiamo nuovamente De l'Hôpital.

limx→0 (sin x)/(2x) = limx→0 (cos x)/2 = cos(0)/2 = 1/2

Esercizio 10 - Minimo assoluto tramite la derivata

Esempio: Studiare la monotonia di f(x) = x2 - 4x + 5 su tutto ℝ, individuando il punto di minimo.

f'(x) = 2x - 4

La derivata è negativa per x < 2 (funzione decrescente) e positiva per x > 2 (funzione crescente).

x = 2 è un punto di minimo assoluto

Esercizio 11 - Un caso in cui il teorema di Rolle non si applica

Esempio: Considerare f(x) = |x| nell'intervallo [-1, 1]. Il teorema di Rolle è applicabile?

f(-1) = 1     f(1) = 1

Sebbene f(-1) = f(1), la funzione non è derivabile in x = 0, punto angoloso interno all'intervallo (come visto nel capitolo sulle derivate): manca quindi l'ipotesi di derivabilità su tutto (-1, 1). Il teorema di Rolle non è applicabile, e infatti non esiste alcun punto c in cui f'(c) = 0: la derivata di f(x) = |x| vale sempre +1 o -1, mai zero.

Esercizio 12 - Esercizio riepilogativo: Lagrange e monotonia sulla stessa funzione

Esempio: Data f(x) = x3 - 3x2 + 2, verificare il teorema di Lagrange nell'intervallo [0, 4] e studiarne separatamente la monotonia.

Calcoliamo prima il rapporto incrementale sull'intervallo.

f(0) = 2     f(4) = 64 - 48 + 2 = 18

[f(4)-f(0)] / (4-0) = (18-2)/4 = 16/4 = 4

Troviamo il punto c per cui f'(c) = 4.

f'(x) = 3x2 - 6x → 3c2 - 6c = 4 → 3c2 - 6c - 4 = 0

Δ = 36 + 48 = 84 → c = (6 + √84) / 6 ≈ 2,53

(l'altra soluzione, negativa, va scartata perché esterna all'intervallo). Studiamo ora la monotonia della stessa funzione, fattorizzando la derivata.

f'(x) = 3x2 - 6x = 3x(x-2)

La derivata è positiva per x < 0 ∨ x > 2, e negativa per 0 < x < 2: quindi x = 0 è un massimo relativo e x = 2 è un minimo relativo, coerentemente con il fatto che il punto c ≈ 2,53 trovato con Lagrange cade proprio nella zona in cui la funzione è di nuovo crescente.
