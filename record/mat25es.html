25 - Esercizi svolti: la parabola

Esercizio 1 - Vertice e asse di simmetria

Esempio: Determinare vertice e asse di simmetria della parabola y = 2x2 - 8x + 5.

xV = -(-8) / (2×2) = 8/4 = 2

Δ = (-8)2 - 4×2×5 = 64 - 40 = 24 → yV = -24/(4×2) = -3

V(2, -3) , asse di simmetria: x = 2

Esercizio 2 - Fuoco e direttrice

Esempio: Determinare fuoco e direttrice della parabola y = x2 - 4x + 3, sapendo che a = 1, b = -4, c = 3 e Δ = 4.

F = ( -(-4)/(2×1) , (1-4)/(4×1) ) = (2, -3/4)

direttrice: y = (-1-4)/(4×1) = -5/4

Esercizio 3 - Intersezioni con gli assi cartesiani

Esempio: Trovare le intersezioni con gli assi della parabola y = 2x2 - 3x - 5.

Poniamo y = 0 per l'intersezione con l'asse x.

Δ = (-3)2 - 4×2×(-5) = 9 + 40 = 49

x = (3 ± 7) / 4 → x1 = 2,5 , x2 = -1

La parabola interseca l'asse x nei punti (2,5 ; 0) e (-1, 0), e interseca l'asse y nel punto (0, -5), dato direttamente dal termine noto c = -5.

Esercizio 4 - Retta secante alla parabola

Esempio: Trovare le intersezioni tra la retta y = 3x - 2 e la parabola y = x2.

x2 = 3x - 2 → x2 - 3x + 2 = 0

Δ = (-3)2 - 4×1×2 = 9 - 8 = 1

Poiché Δ > 0, la retta è secante: risolviamo per trovare i due punti.

x = (3 ± 1) / 2 → x1 = 2 , x2 = 1

Sostituendo troviamo i punti (2, 4) e (1, 1), verificabili anche con l'equazione della retta: 3×2-2=4 e 3×1-2=1.

Esercizio 5 - Retta tangente alla parabola

Esempio: Verificare se la retta y = 6x - 9 è tangente alla parabola y = x2.

x2 = 6x - 9 → x2 - 6x + 9 = 0

Δ = (-6)2 - 4×1×9 = 36 - 36 = 0

Il discriminante è nullo: la retta è tangente, nel punto di ascissa doppia x = 6/2 = 3, con ordinata y = 32 = 9. Il punto di tangenza è (3, 9).

Esercizio 6 - Retta esterna alla parabola

Esempio: Verificare la posizione della retta y = 2x - 3 rispetto alla parabola y = x2 + 4.

x2 + 4 = 2x - 3 → x2 - 2x + 7 = 0

Δ = (-2)2 - 4×1×7 = 4 - 28 = -24

Il discriminante è negativo: la retta è esterna alla parabola, senza alcun punto in comune.

Esercizio 7 - Parabola per tre punti dati

Esempio: Determinare l'equazione della parabola passante per A(0,1), B(1,4) e C(-1,2).

Sostituendo A(0,1) nell'equazione generale si ottiene subito c = 1.

B(1,4): a + b + c = 4 → a + b = 3

C(-1,2): a - b + c = 2 → a - b = 1

Sommando le due equazioni si elimina b.

2a = 4 → a = 2 → b = 3 - 2 = 1

y = 2x2 + x + 1

Verifichiamo con B: 2 + 1 + 1 = 4, e con C: 2 - 1 + 1 = 2.

Esercizio 8 - Parabola dati vertice e un punto

Esempio: Determinare l'equazione della parabola con vertice V(-1, 2) e passante per A(1, 10).

Dalla condizione sul vertice, -b/(2a) = -1, cioè b = 2a. Sostituiamo V e la relazione b = 2a nell'equazione generale.

V(-1,2): a - b + c = 2 → a - 2a + c = 2 → -a + c = 2

A(1,10): a + b + c = 10 → a + 2a + c = 10 → 3a + c = 10

Sottraendo la prima equazione dalla seconda si elimina c.

4a = 8 → a = 2 → c = 2 + a = 4 → b = 2a = 4

y = 2x2 + 4x + 4

Verifichiamo il vertice: xV = -4/(2×2) = -1, e yV = 2 - 4 + 4 = 2, coerente con V(-1, 2).

Esercizio 9 - Nessuna intersezione con l'asse x

Esempio: Stabilire quante intersezioni ha con l'asse x la parabola y = 3x2 - 2x + 5.

Δ = (-2)2 - 4×3×5 = 4 - 60 = -56

Il discriminante è negativo: la parabola non interseca l'asse x in alcun punto.

Esercizio 10 - Parabola tangente all'asse x

Esempio: Stabilire quante intersezioni ha con l'asse x la parabola y = 4x2 - 12x + 9, e trovarle.

Δ = (-12)2 - 4×4×9 = 144 - 144 = 0

Il discriminante è nullo: la parabola è tangente all'asse x in un solo punto, di ascissa x = 12/8 = 1,5. Il punto è (1,5 ; 0).

Esercizio 11 - Trovare l'apertura dal fuoco e dal vertice

Esempio: Una parabola ha vertice V(0, 0) e fuoco F(0, 2). Determinare il coefficiente a e l'equazione della parabola.

La distanza tra fuoco e vertice è pari a 1/(4a).

1/(4a) = 2 → 4a = 1/2 → a = 1/8

y = (1/8)x2

Esercizio 12 - Esercizio riepilogativo: vertice, intersezioni e posizione di una retta

Esempio: Data la parabola y = x2 - 6x + 8, determinare vertice e intersezioni con gli assi, poi verificare se la retta y = -2x + 7 è tangente alla parabola.

Calcoliamo il vertice.

xV = 6/2 = 3     Δ = (-6)2 - 4×1×8 = 4 → yV = -4/4 = -1 → V(3, -1)

Troviamo le intersezioni con l'asse x, cercando due numeri il cui prodotto sia 8 e la cui somma sia 6, cioè 2 e 4.

x2 - 6x + 8 = (x-2)(x-4) = 0 → x = 2 , x = 4

L'intersezione con l'asse y è il punto (0, 8). Verifichiamo ora la retta data.

x2 - 6x + 8 = -2x + 7 → x2 - 4x + 1 = 0

Δ = (-4)2 - 4×1×1 = 16 - 4 = 12

Il discriminante è positivo: la retta non è tangente, ma secante, e interseca la parabola in due punti distinti.
