32 - Equazioni e disequazioni goniometriche - Classe 4

Le equazioni goniometriche elementari

Un'equazione goniometrica è un'equazione in cui l'incognita compare all'interno di una funzione goniometrica. Le equazioni goniometriche elementari sono quelle riconducibili a una delle tre forme fondamentali: sin x = m, cos x = m oppure tan x = m.

Per l'equazione sin x = m, occorre distinguere due casi: se m è compreso tra -1 e 1 (estremi inclusi), esistono infinite soluzioni, perché la funzione seno è periodica; se invece |m| è maggiore di 1, l'equazione è impossibile, perché il seno non può mai superare, in valore assoluto, il valore 1.

Quando esiste almeno una soluzione α, tutte le altre soluzioni si ottengono considerando anche l'angolo supplementare, e aggiungendo poi un multiplo intero dell'angolo giro, per tenere conto della periodicità.

sin x = m → x = α + 2kπ ∨ x = (π - α) + 2kπ , con k ∈ ℤ

Risolviamo l'equazione sin x = 1/2. Sappiamo che sin(π/6) = 1/2, quindi α = π/6.

x = π/6 + 2kπ ∨ x = π - π/6 + 2kπ = 5π/6 + 2kπ , con k ∈ ℤ

In modo analogo, per l'equazione cos x = m, con |m| ≤ 1, le soluzioni si ottengono considerando l'angolo opposto oltre a quello trovato.

cos x = m → x = ±α + 2kπ , con k ∈ ℤ

Per l'equazione tan x = m, che ammette sempre soluzione qualunque sia il valore reale m (dato che la tangente assume tutti i valori reali), basta invece aggiungere un multiplo intero di π, dato che il periodo della tangente è proprio π.

tan x = m → x = α + kπ , con k ∈ ℤ

Equazioni lineari in seno e coseno

Un'equazione goniometrica si dice lineare in seno e coseno quando ha la forma a sin x + b cos x + c = 0, con a e b non entrambi nulli. Quando il termine noto c è uguale a zero, l'equazione si dice omogenea, e si risolve dividendo tutto per cos x (verificando prima che cos x = 0 non sia soluzione), trasformandola così in un'equazione nella sola tangente.

Risolviamo l'equazione omogenea sin x - √3 cos x = 0. Verifichiamo che cos x = 0 non sia soluzione: se cos x = 0 allora anche sin x dovrebbe essere 0, ma questo è impossibile per la prima relazione fondamentale. Dividiamo quindi tutto per cos x.

tan x - √3 = 0 → tan x = √3 → x = π/3 + kπ , con k ∈ ℤ

Quando invece il termine noto c non è nullo, si parla di equazione lineare completa, e si risolve solitamente con il metodo dell'angolo aggiunto, oppure tramite le formule parametriche, che esprimono seno e coseno in funzione della tangente del semiangolo, riconducendo l'equazione a un'equazione algebrica di secondo grado in una nuova incognita t = tan(x/2).

sin x = 2t / (1 + t2) , cos x = (1 - t2) / (1 + t2)

Le disequazioni goniometriche elementari

Una disequazione goniometrica elementare si risolve in modo analogo alle equazioni, ma utilizzando la circonferenza goniometrica per individuare graficamente l'arco (o gli archi) di soluzioni, invece di singoli punti. Si individuano prima i punti della circonferenza in cui la funzione vale esattamente il valore limite, per poi determinare in quale porzione della circonferenza la disuguaglianza risulta verificata.

Risolviamo la disequazione sin x > 1/2, limitandoci per semplicità all'intervallo [0, 2π). Sulla circonferenza goniometrica, il seno rappresenta l'ordinata del punto: dobbiamo trovare dove questa ordinata supera 1/2.

I punti in cui sin x = 1/2 sono x = π/6 e x = 5π/6. L'ordinata è maggiore di 1/2 nell'arco compreso tra questi due angoli (la parte "alta" della circonferenza).

π/6 < x < 5π/6

Se si vogliono tutte le soluzioni sull'intero asse reale, e non solo in un periodo, si aggiunge 2kπ, con k intero, a tutta la soluzione trovata.

π/6 + 2kπ < x < 5π/6 + 2kπ , con k ∈ ℤ

Disequazioni con coseno e tangente

Per le disequazioni con il coseno, si procede in modo analogo, ricordando che il coseno rappresenta l'ascissa del punto sulla circonferenza goniometrica, quindi le regioni di validità si trovano confrontando l'ascissa con il valore limite, invece dell'ordinata.

Risolviamo cos x ≤ 1/2, nell'intervallo [0, 2π). I punti in cui cos x = 1/2 sono x = π/3 e x = 5π/3. L'ascissa è minore o uguale a 1/2 nell'arco esterno a questi due valori, cioè dalla parte "sinistra" della circonferenza.

π/3 ≤ x ≤ 5π/3

Per le disequazioni con la tangente, si ragiona invece sulla retta tangente alla circonferenza goniometrica nel punto (1,0), tenendo sempre presente che il periodo è π e che la funzione non è definita per x = π/2 + kπ.

Sistemi di disequazioni goniometriche

Quando un problema richiede la soluzione simultanea di più disequazioni goniometriche, si risolve ciascuna disequazione separatamente sulla circonferenza goniometrica, per poi sovrapporre graficamente gli archi di soluzione trovati e individuarne l'intersezione, esattamente come già fatto per i sistemi di disequazioni algebriche.

Risolviamo il sistema formato da sin x > 0 e cos x > 0, nell'intervallo [0, 2π). La prima disequazione è verificata nel primo e secondo quadrante (0 < x < π); la seconda è verificata nel primo e quarto quadrante (0 ≤ x < π/2 ∨ 3π/2 < x < 2π).

L'intersezione di questi due archi corrisponde esattamente al primo quadrante, l'unico in cui sia il seno sia il coseno sono positivi contemporaneamente.

0 < x < π/2
