04 - Esercizi svolti: frazioni algebriche

Esercizio 1 - Condizioni di esistenza con denominatore semplice

Esempio: Determinare le condizioni di esistenza della frazione algebrica (2x - 1) / (x + 5).

Il denominatore non deve mai annullarsi: poniamo x + 5 ≠ 0.

C.E.: x ≠ -5

Esercizio 2 - Condizioni di esistenza con denominatore da scomporre

Esempio: Determinare le condizioni di esistenza della frazione (x + 1) / (x2 - 9).

Scomponiamo il denominatore come differenza di quadrati prima di imporre le condizioni.

x2 - 9 = (x + 3)(x - 3)

La frazione perde significato se anche uno solo dei due fattori si annulla.

C.E.: x ≠ -3, x ≠ 3

Esercizio 3 - Semplificazione con raccoglimento a fattor comune

Esempio: Semplificare la frazione (6x3 - 9x2) / (3x2).

Scomponiamo il numeratore raccogliendo il fattore comune 3x2.

(6x3 - 9x2) / (3x2) = [3x2(2x - 3)] / (3x2) = 2x - 3, con C.E.: x ≠ 0

Esercizio 4 - Semplificazione con differenza di quadrati

Esempio: Semplificare la frazione (x2 - 25) / (x2 - 5x).

Scomponiamo numeratore e denominatore.

(x2 - 25) / (x2 - 5x) = [(x + 5)(x - 5)] / [x(x - 5)]

Il fattore (x - 5) è comune e si può semplificare, ricordando che deve restare diverso da zero.

= (x + 5) / x, con C.E.: x ≠ 0, x ≠ 5

Esercizio 5 - Semplificazione con trinomio notevole

Esempio: Semplificare la frazione (x2 - x - 6) / (x2 - 4).

Scomponiamo il numeratore come trinomio notevole di secondo grado, cercando due numeri il cui prodotto sia -6 e la cui somma sia -1: sono -3 e 2. Il denominatore è una differenza di quadrati.

(x2 - x - 6) / (x2 - 4) = [(x - 3)(x + 2)] / [(x + 2)(x - 2)]

Il fattore (x + 2) è comune.

= (x - 3) / (x - 2), con C.E.: x ≠ -2, x ≠ 2

Esercizio 6 - Moltiplicazione di frazioni algebriche

Esempio: Calcolare il prodotto [(x + 2) / x] × [x2 / (x2 - 4)].

Scomponiamo x2 - 4 come differenza di quadrati prima di moltiplicare.

[(x + 2) / x] × [x2 / ((x+2)(x-2))] = [x2(x + 2)] / [x(x+2)(x-2)]

Semplifichiamo i fattori comuni x e (x + 2).

= x / (x - 2), con C.E.: x ≠ 0, x ≠ 2, x ≠ -2

Esercizio 7 - Divisione di frazioni algebriche

Esempio: Calcolare [(x2 - 1) / x] : [(x + 1) / x2].

Si moltiplica la prima frazione per il reciproco della seconda, poi si scompone e si semplifica.

[(x2 - 1) / x] × [x2 / (x + 1)] = [(x+1)(x-1) × x2] / [x(x+1)]

= x(x - 1), con C.E.: x ≠ 0, x ≠ -1

Esercizio 8 - Addizione con lo stesso denominatore

Esempio: Calcolare 3/(x - 1) + 5/(x - 1).

Il denominatore è comune, quindi si sommano direttamente i numeratori.

3/(x - 1) + 5/(x - 1) = 8/(x - 1), con C.E.: x ≠ 1

Esercizio 9 - Addizione con denominatori diversi senza fattori comuni

Esempio: Calcolare 2/x - 3/(x - 2).

I due denominatori non hanno fattori comuni: il minimo comune denominatore è il loro prodotto x(x - 2).

2/x - 3/(x - 2) = [2(x-2)]/[x(x-2)] - [3x]/[x(x-2)] = (2x - 4 - 3x)/[x(x-2)] = (-x - 4)/[x(x-2)]

con C.E.: x ≠ 0, x ≠ 2

Esercizio 10 - Addizione con denominatori che condividono un fattore

Esempio: Calcolare 1/(x2 - 1) + 2/(x + 1).

Scomponiamo il primo denominatore: x2 - 1 = (x + 1)(x - 1). Il minimo comune denominatore è (x + 1)(x - 1).

1/[(x+1)(x-1)] + 2/(x+1) = 1/[(x+1)(x-1)] + [2(x-1)]/[(x+1)(x-1)] = (1 + 2x - 2)/[(x+1)(x-1)] = (2x - 1)/[(x+1)(x-1)]

con C.E.: x ≠ -1, x ≠ 1

Esercizio 11 - Espressione con più operazioni

Esempio: Semplificare l'espressione [(x + 1)/x] × [(x - 1)/(x + 1)] + 1/x.

Prima si esegue la moltiplicazione, semplificando il fattore comune (x + 1).

[(x + 1)/x] × [(x - 1)/(x + 1)] = (x - 1)/x

Ora sommiamo il risultato a 1/x, che ha già lo stesso denominatore.

(x - 1)/x + 1/x = (x - 1 + 1)/x = x/x = 1, con C.E.: x ≠ 0, x ≠ -1

Approfondimento: anche se il risultato finale si semplifica fino a diventare 1, le condizioni di esistenza calcolate sui passaggi intermedi restano comunque valide e vanno sempre riportate.

Esercizio 12 - Esercizio riepilogativo

Esempio: Semplificare l'espressione [(x2 - 4)/(x2 + 4x + 4)] : [(x - 2)/(x + 2)].

Scomponiamo numeratore e denominatore della prima frazione: x2 - 4 è una differenza di quadrati, x2 + 4x + 4 è il quadrato di un binomio.

[(x+2)(x-2)] / (x+2)2 : [(x-2)/(x+2)]

Semplifichiamo la prima frazione, poi trasformiamo la divisione in moltiplicazione per il reciproco.

= [(x-2)/(x+2)] × [(x+2)/(x-2)] = 1, con C.E.: x ≠ -2, x ≠ 2
