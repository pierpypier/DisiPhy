44 - Esercizi svolti: cenni di equazioni differenziali

Esercizio 1 - Equazione differenziale y' = f(x): soluzione generale

Esempio: Risolvere l'equazione differenziale y' = 4x3 - 2x.

La soluzione generale si ottiene integrando il secondo membro.

y = ∫ (4x3 - 2x) dx = x4 - x2 + c

Esercizio 2 - Problema di Cauchy associato

Esempio: Risolvere il problema di Cauchy formato dall'equazione y' = 4x3 - 2x (dall'Esercizio 1) e dalla condizione y(1) = 3.

Partiamo dalla soluzione generale già trovata e imponiamo la condizione iniziale.

3 = 14 - 12 + c → 3 = 0 + c → c = 3

La soluzione particolare è quindi y = x4 - x2 + 3.

Esercizio 3 - Equazione differenziale con funzione trigonometrica

Esempio: Risolvere l'equazione differenziale y' = cos x.

y = ∫ cos x dx = sin x + c

Esercizio 4 - Problema di Cauchy trigonometrico

Esempio: Risolvere il problema di Cauchy formato dall'equazione y' = cos x (dall'Esercizio 3) e dalla condizione y(0) = 2.

2 = sin(0) + c → 2 = 0 + c → c = 2

La soluzione particolare è quindi y = sin x + 2.

Esercizio 5 - Equazione a variabili separabili

Esempio: Risolvere l'equazione differenziale y' = 2xy.

Riscriviamo come dy/dx = 2xy, e separiamo le variabili.

dy/y = 2x dx

Integriamo entrambi i membri separatamente.

∫ dy/y = ∫ 2x dx → ln|y| = x2 + c1

Esplicitiamo y applicando l'esponenziale, e assorbendo le costanti come nel capitolo.

y = c × ex2

Esercizio 6 - Problema di Cauchy a variabili separabili

Esempio: Risolvere il problema di Cauchy formato dall'equazione y' = 2xy (dall'Esercizio 5) e dalla condizione y(0) = 5.

Imponiamo la condizione iniziale sulla soluzione generale trovata.

5 = c × e0 = c → c = 5

La soluzione particolare è quindi y = 5 × ex2. Verifichiamo derivando: y' = 5 × 2x × ex2 = 2x × (5ex2) = 2xy, coerente con l'equazione di partenza.

Esercizio 7 - Equazione a variabili separabili: caso y'=y/x

Esempio: Risolvere l'equazione differenziale y' = y/x, per x > 0.

dy/y = dx/x → ln|y| = ln|x| + c1 → y = c × x

Verifichiamo per sostituzione: se y = cx, allora y' = c, e y/x = cx/x = c, coerenti tra loro.

Esercizio 8 - Applicazione: decadimento radioattivo

Esempio: Una sostanza radioattiva ha costante di decadimento k = 0,1 e quantità iniziale N0 = 200 g. Calcolare la quantità di sostanza rimasta dopo 10 unità di tempo.

Applichiamo la formula del decadimento esponenziale vista nel capitolo.

N(t) = N0 × e-kt = 200 × e-0,1×10 = 200 × e-1 ≈ 200 × 0,368 ≈ 73,58 g

Esercizio 9 - Applicazione: crescita esponenziale

Esempio: Una popolazione batterica cresce con costante k = 0,05 e popolazione iniziale N0 = 1000. Calcolare la popolazione dopo 20 unità di tempo.

Nel caso di crescita, la costante ha segno positivo nell'esponente.

N(t) = N0 × ekt = 1000 × e0,05×20 = 1000 × e1 ≈ 1000 × 2,718 ≈ 2718,28

Esercizio 10 - Tempo di dimezzamento

Esempio: Per la sostanza radioattiva dell'Esercizio 8 (k = 0,1), calcolare il tempo di dimezzamento, cioè il tempo necessario perché la quantità si riduca alla metà.

Imponiamo N(t) = N0/2 nella formula del decadimento.

N0/2 = N0 × e-kt → 1/2 = e-0,1t → ln(1/2) = -0,1t

t = ln(2) / 0,1 ≈ 0,693 / 0,1 ≈ 6,93

Esercizio 11 - Equazione a variabili separabili: caso y'=x/y

Esempio: Risolvere l'equazione differenziale y' = x/y, con y > 0.

Separiamo le variabili portando la y (con dy) al primo membro.

y dy = x dx

Integriamo entrambi i membri.

∫ y dy = ∫ x dx → y2/2 = x2/2 + c1 → y2 = x2 + c

La soluzione, in questo caso, resta espressa in forma implicita; esplicitando per y > 0 si ottiene y = √(x2+c).

Esercizio 12 - Esercizio riepilogativo: problema di Cauchy con applicazione fisica

Esempio: Risolvere il problema di Cauchy formato dall'equazione y' = -3y e dalla condizione y(0) = 50, poi calcolare y(2).

Separiamo le variabili come negli esercizi precedenti.

dy/y = -3 dx → ln|y| = -3x + c1 → y = c × e-3x

Imponiamo la condizione iniziale.

50 = c × e0 = c → c = 50

La soluzione particolare è quindi y = 50 × e-3x, che rappresenta un decadimento esponenziale con costante k = 3. Calcoliamo infine il valore richiesto.

y(2) = 50 × e-3×2 = 50 × e-6 ≈ 50 × 0,00248 ≈ 0,124
