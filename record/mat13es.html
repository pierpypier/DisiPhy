13 - Esercizi svolti: disequazioni di secondo grado

Esercizio 1 - Δ > 0, verso "maggiore" (soluzione esterna)

Esempio: Risolvere la disequazione x2 - x - 6 > 0.

Risolviamo l'equazione associata: cerchiamo due numeri il cui prodotto sia -6 e la cui somma sia 1, cioè 3 e -2.

x1 = -2, x2 = 3

Poiché a è positivo e il verso è "maggiore", la soluzione è data dai valori esterni all'intervallo delle radici.

x < -2 ∨ x > 3

Esercizio 2 - Δ > 0, verso "minore" (soluzione interna)

Esempio: Risolvere la disequazione x2 - 2x - 8 < 0.

Risolviamo l'equazione associata: cerchiamo due numeri il cui prodotto sia -8 e la cui somma sia 2, cioè 4 e -2.

x1 = -2, x2 = 4

Poiché a è positivo e il verso è "minore", la soluzione è data dai valori interni all'intervallo delle radici.

-2 < x < 4

Esercizio 3 - Δ > 0 con disuguaglianza non stretta

Esempio: Risolvere la disequazione x2 - 9 ≥ 0.

L'equazione associata x2 - 9 = 0 ha soluzioni x = ±3.

x1 = -3, x2 = 3

Il verso è "maggiore o uguale": prendiamo i valori esterni, includendo questa volta anche le radici stesse.

x ≤ -3 ∨ x ≥ 3

Esercizio 4 - Δ = 0, verso "maggiore" stretto

Esempio: Risolvere la disequazione x2 - 6x + 9 > 0.

Riconosciamo il trinomio come quadrato di un binomio.

x2 - 6x + 9 = (x - 3)2

Un quadrato è sempre maggiore o uguale a zero, e vale zero solo per x = 3: la disequazione stretta è quindi verificata per ogni x diverso da 3.

x ≠ 3

Esercizio 5 - Δ = 0, verso "maggiore o uguale"

Esempio: Risolvere la disequazione x2 + 4x + 4 ≥ 0.

x2 + 4x + 4 = (x + 2)2

Poiché un quadrato è sempre maggiore o uguale a zero, la disequazione è verificata per ogni valore reale di x, incluso x = -2.

soluzione: ∀x ∈ ℝ

Esercizio 6 - Δ = 0, verso "minore" stretto (caso impossibile)

Esempio: Risolvere la disequazione x2 - 10x + 25 < 0.

x2 - 10x + 25 = (x - 5)2

Un quadrato non può mai essere negativo: la disequazione non ha alcuna soluzione.

Esercizio 7 - Δ < 0, verso "maggiore" (sempre verificata)

Esempio: Risolvere la disequazione x2 + 2x + 5 > 0.

Calcoliamo il discriminante dell'equazione associata.

Δ = 22 - 4×1×5 = 4 - 20 = -16

Poiché a è positivo e Δ è negativo, la parabola è sempre al di sopra dell'asse delle ascisse: la disequazione è verificata per ogni x reale.

soluzione: ∀x ∈ ℝ

Esercizio 8 - Δ < 0, verso "minore" (impossibile)

Esempio: Risolvere la disequazione x2 + x + 2 < 0.

Δ = 12 - 4×1×2 = 1 - 8 = -7

Poiché a è positivo e Δ è negativo, la parabola non scende mai sotto l'asse delle ascisse: la disequazione non ha soluzioni.

Esercizio 9 - Coefficiente a negativo: cambio di verso preliminare

Esempio: Risolvere la disequazione -x2 + 5x - 6 > 0.

Il coefficiente di x2 è negativo: moltiplichiamo entrambi i membri per -1, ricordando di invertire il verso della disequazione.

-x2 + 5x - 6 > 0 → x2 - 5x + 6 < 0

Risolviamo l'equazione associata: cerchiamo due numeri il cui prodotto sia 6 e la cui somma sia 5, cioè 2 e 3.

x1 = 2, x2 = 3

Il verso è "minore": la soluzione è l'intervallo interno alle radici.

2 < x < 3

Esercizio 10 - Disequazione fratta

Esempio: Risolvere la disequazione (x + 3) / (x - 2) ≤ 0.

Studiamo separatamente il segno di numeratore e denominatore. Il numeratore x + 3 è maggiore o uguale a zero per x ≥ -3. Il denominatore x - 2 è maggiore di zero per x > 2 (e non può mai essere zero, quindi x ≠ 2).

Costruendo il grafico dei segni: per x < -3 entrambi i fattori sono negativi, quindi la frazione è positiva; per -3 ≤ x < 2 il numeratore è positivo o nullo e il denominatore è negativo, quindi la frazione è negativa o nulla; per x > 2 entrambi sono positivi, quindi la frazione è positiva.

-3 ≤ x < 2

Esercizio 11 - Sistema di disequazioni di secondo e primo grado

Esempio: Risolvere il sistema formato da x2 - 4 > 0 e x + 1 > 0.

Risolviamo separatamente le due disequazioni. La prima ha equazione associata con soluzioni x = ±2.

x2 - 4 > 0 → x < -2 ∨ x > 2

x + 1 > 0 → x > -1

La soluzione del sistema è l'intersezione delle due soluzioni. L'intervallo x < -2 non ha punti in comune con x > -1, mentre l'intervallo x > 2 è interamente contenuto in x > -1.

x > 2

Esercizio 12 - Esercizio riepilogativo: sistema con disequazione fratta

Esempio: Risolvere il sistema formato da x2 - 5x + 6 ≤ 0 e (x - 1) / (x + 4) > 0.

Risolviamo la prima disequazione: l'equazione associata ha soluzioni x1 = 2 e x2 = 3; essendo il verso "minore o uguale", la soluzione è l'intervallo interno, radici incluse.

2 ≤ x ≤ 3

Risolviamo ora la disequazione fratta studiando i segni di numeratore e denominatore: il numeratore x - 1 è positivo per x > 1, il denominatore x + 4 è positivo per x > -4. La frazione è positiva quando i due fattori hanno lo stesso segno.

(x - 1) / (x + 4) > 0 → x < -4 ∨ x > 1

Intersechiamo le due soluzioni: l'intervallo x < -4 non ha punti in comune con [2, 3], mentre l'intervallo x > 1 contiene interamente [2, 3].

2 ≤ x ≤ 3
